Empire Tap Privacy Policy

This folder contains the privacy-policy materials for **Empire Tap**.

## Publish to GitHub Pages

1. Copy the privacy-policy page into the root of the `empire-tap-privacy` repository as `index.html`.
2. In the repository, open **Settings → Pages**.
3. Deploy from the `main` branch and the `/ (root)` folder.

The expected public policy address is:

`https://ttiger6115-svg.github.io/empire-tap-privacy/`

## Contents

- `PRIVACY_POLICY_DRAFT.md` — source wording for the policy.
- `README.md` — publishing notes for this policy folder.

Review and update the policy whenever Empire Tap adds data collection, analytics, account features, or advertising changes.
